## Nguyên Tắc Viết Docs

- Viết tiếng Việt có dấu cho tài liệu sản phẩm và kế hoạch.
- Giữ thuật ngữ kỹ thuật tiếng Anh khi đó là tên chuẩn: `frontend`, `backend`, `queue`, `cache`, `rate limit`, `DTO`.
- Mỗi phase phải có mục tiêu, phạm vi, đầu ra, checklist và tiêu chí hoàn thành.
- Khi có quyết định thay đổi stack hoặc phạm vi, cập nhật roadmap tổng trước rồi cập nhật phase liên quan.

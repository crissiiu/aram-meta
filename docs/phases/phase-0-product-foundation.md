# Phase 0: Nền Tảng Sản Phẩm

## Mục Tiêu

Chốt định hướng sản phẩm, luồng người dùng, sitemap và nguyên tắc tuân thủ Riot trước khi scaffold code.

## Phạm Vi

Bao gồm:

- Tầm nhìn sản phẩm.
- Sitemap.
- Ghi chú tuân thủ Riot.
- README dự án.

Không bao gồm:

- Code frontend/backend.
- Database schema.
- Tích hợp Riot API thật.

## Đầu Ra

- `docs/product/vision.md`
- `docs/product/sitemap.md`
- `docs/product/riot-compliance.md`

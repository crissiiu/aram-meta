# Sitemap

## Điều Hướng Chính

- Home
- Tier List
- Champions
- Items
- Guides
- Player Search
- Leaderboard
- Community
- Patch Notes

## Trang Home

Mục tiêu: đưa người dùng tới tier list hoặc ô tìm kiếm tướng/người chơi nhanh nhất.

Nội dung chính:

- Thanh tìm kiếm tướng.
- Link vào tier list ARAM mới nhất.
- Một vài tướng mạnh trong patch hiện tại.
- Trạng thái dữ liệu: patch, thời điểm cập nhật gần nhất.

## Trang Tier List

Mục tiêu: giúp người chơi lọc và so sánh tướng ARAM.

Bộ lọc:

- Patch.
- Region.
- Rank bracket nếu dữ liệu đủ tin cậy.
- Vai trò/playstyle nếu đã phân loại.

Thông tin hiển thị:

- Tên tướng.
- Tier.
- Win rate.
- Pick rate.
- Sample size.
- Build khuyến nghị ngắn.

## Trang Chi Tiết Tướng

Mục tiêu: trả lời câu hỏi "tướng này nên lên gì trong ARAM?"

Nội dung:

- Core items.
- Situational items.
- Boots.
- Runes hoặc lựa chọn tương đương nếu dữ liệu hỗ trợ.
- Phép bổ trợ.
- Win rate/pick rate/sample size.
- Ghi chú cách chơi và điều kiện đổi build.

## Trang Player Search

Mục tiêu: tra cứu người chơi bằng Riot ID.

Trạng thái MVP sau:

- Tìm bằng `gameName`, `tagLine`, region.
- Hiển thị profile cơ bản.
- Link sang lịch sử đấu ARAM.

## Trang Community

Mục tiêu: đưa người dùng vào Discord hoặc flow lập đội.

Giai đoạn đầu chỉ cần link Discord rõ ràng. Chat trong site chỉ nên làm sau khi có nhu cầu thật và moderation.
